题页 · 试卷转 PPT / 希沃课件 · 免安装离线版

Windows 使用方法：
1. 完整解压压缩包，不要在压缩软件里直接运行。
2. 双击同一文件夹中的 index.html，用 Microsoft Edge 或 Google Chrome 打开。
   GitHub 下载包的根目录 index.html 会自动打开 offline/index.html；也可直接打开后者。
   如果默认打开的是其他程序，右键 index.html → 打开方式 → Microsoft Edge。
3. 选择 PDF 或 Word（.docx）试卷，检查分题结果后导出。

不需要 Python、不需要 Node.js、不需要命令行，也不需要启动本地服务。
程序、PDF 字体、中英文 OCR 引擎及示例均在 HTML 内，断网也能使用。
HTML 约 17 MB，首次打开请稍候。macOS / Linux 也可用 Chrome 打开。

导出格式：
PowerPoint：标准 .pptx，题干是图片，标题可编辑。
希沃导入版：整页图片 .pptx，在希沃白板中选择「导入课件」。
希沃原生：.enbx（试用），整页图片，每题一页，用希沃白板 5 打开。
原生课件经过结构和独立读取器校验，实际希沃版本兼容性仍需确认。

扫描试卷可点击「扫描件 OCR」；识别后请检查选框，必要时手动框选或调整。
旧版 .doc 请先用 Word / WPS 另存为 .docx 或 PDF。
文件在浏览器本地处理，不上传试卷。刷新或关闭页面会清空当前工作。

GitHub 仓库主页 → Code → Download ZIP，完整解压后即可使用。
仓库同时保存源码 src/ 和可运行版本 offline/，下载后不需要自己构建。
如果仍看到要求 Python 的旧提示，请重新下载 main 分支并解压到新文件夹。
licenses 文件夹保存第三方授权文本，请随程序一起保留。
