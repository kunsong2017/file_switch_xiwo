# 答案与解析数据

这里存放两份用户真卷的人工解答，用来演示和回归「答案与解析」功能。

| 文件 | 对应试卷 | 题数 |
|---|---|---|
| `期中综合复习2.json` | `tests/初三数学期中综合复习2.pdf` | 1～27 |
| `复习卷6.json` | `tests/初三数学复习卷 6.pdf` | 1～26 |

## 格式

```json
{
  "paper": "试卷名称",
  "questions": [
    {"number": 1, "answer": "D", "analysis": "形如 y=k/x（k≠0）……"}
  ]
}
```

导入时按 `number` 与拆分出的题号匹配；没有题号的试卷（手动框选）按顺序匹配。

## 在网页里使用

1. 导入试卷并确认题目拆分。
2. 点工具栏「答案与解析」→「导入 JSON」，选择这里的文件。
3. 在「课件设置 → 答案与解析」选择：
   - **同页点击出现**：解析、答案先隐藏，放映时依次点击出现（PowerPoint / WPS）；
   - **每题后一页**：题目一页、解析一页，翻页即出现（PowerPoint、希沃导入版、希沃原生三种格式通用）。
4. 没有 JSON 时也可以在「当前题目」里逐题填写，或把答案粘贴到「批量粘贴」框。

答案与解析只在浏览器内存中，刷新即清空；可用「导出当前答案」保存成 JSON。

> 这两份解答是人工整理的参考解答，上课前请按自己的班级情况再核对一遍。
